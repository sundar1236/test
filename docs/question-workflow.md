# Question Lifecycle & Workflow Specification

```text
 ( Draft ) ───► ( Under Review ) ───► ( Validated ) ───► ( Published ) ───► ( Archived )
```

---

## Stages & Rules

### 1. Draft
* **Description:** Initial question creation stage.
* **Access:** Question Creator.
* **Actions:** Edit text, options, difficulty, topic.

### 2. Under Review / Pending
* **Description:** Submitted for accuracy check and AI suggested answer validation.
* **Access:** Question Reviewer, Admin, Super Admin.
* **Actions:** Compare source answer vs AI answer, leave audit notes, request changes or approve.

### 3. Validated
* **Description:** Verified by content reviewer as accurate.
* **Access:** Admin, Super Admin.
* **Actions:** Select for inclusion in upcoming published mock test series.

### 4. Published
* **Description:** Live question available for mock exam generation and student practice.
* **Access:** Public / Student (Read via mock tests), Admin (Manage/Archive).
* **Safeguards:** Modifications to published questions log an administrative audit record.

### 5. Archived
* **Description:** Inactive or deprecated question.
* **Access:** Admin, Super Admin.
