# Performance Evaluation & Threshold Rules

## Performance Levels

- **High / Strong:** Accuracy $\ge 80\%$ (minimum 10 attempted questions).
- **Good / Improving:** Accuracy between $70\%$ and $79\%$.
- **Needs Improvement:** Accuracy between $50\%$ and $69\%$.
- **Weak:** Accuracy $< 50\%$ (sample size $\ge 5$).

## Minimum Sample Size Safeguard
A topic is classified as **Learning** until at least **5 questions** have been attempted in test conditions.
