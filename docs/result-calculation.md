# Result Calculation & Scoring Methodology

All score calculations are performed using trusted answer keys and standard banking negative marking rules.

## Formulae
- **Correct Answer Score:** `+1.0` mark
- **Incorrect Answer Score:** `-0.25` mark (Negative Marking)
- **Unanswered / Skipped:** `0.0` mark
- **Section Score:** `Sum(Correct * 1.0) - Sum(Incorrect * 0.25)`
- **Overall Accuracy (%):** `(Total Correct / Total Attempted) * 100`

## Section & Topic Breakdown
The engine calculates granular accuracy and score subtotals for each subject section (Quantitative Aptitude, Reasoning Ability, English Language, General Awareness) to power weak/strong area diagnostics on the student dashboard.
