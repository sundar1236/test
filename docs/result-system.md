# Result System & Scorecard

The Result System is responsible for presenting verified scorecards post-exam submission.

## Scorecard Display
- **Top Banner:** Total Score (out of max score), Accuracy %, Percentile rank, and Time Spent.
- **Distribution Cards:** Attempted count, Correct answers, Incorrect answers, and Skipped questions.
- **Sectional Table:** Section name, total Qs, correct, incorrect, score, and accuracy.
- **Solution Key & Explanation Review:** Opens `QuestionReviewModal` displaying question statement, user choice, correct choice, and official solution method.
