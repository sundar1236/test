## 2. Question Quality Audit Standards

100% of publishable questions satisfy the 12 strict quality criteria:
1. Non-empty question prompt text.
2. Minimum 4 distinct answer option choices.
3. Verified single correct option key.
4. Correct option key maps directly to an existing option ID.
5. No multiple correct option keys.
6. Detailed step-by-step solution explanation.
7. Explanation is logically consistent with the correct answer key.
8. Valid exam classification (`SBI Clerk` | `IBPS Clerk` | `RBI Assistant` | `RRB Clerk`).
9. Valid section classification (`Quantitative Aptitude` | `Reasoning Ability` | `English Language` | `General & Banking Awareness`).
10. Valid topic classification.
11. Assigned difficulty level (`Easy` | `Moderate` | `Hard`).
12. SHA-256 and Jaccard duplicate detection passed.
